# PrintFlow ERP

ต้นแบบ ERP ภาษาไทยสำหรับโรงพิมพ์กล่อง บรรจุภัณฑ์ และสติ๊กเกอร์แบบแผ่น

## เปิดเว็บไซต์

[ทดลอง PrintFlow ERP](https://nk02388-cyber.github.io/PrintFlow-ERP/)

## ความสามารถ

- ประเมินราคา: กระดาษ เผื่อเสีย ตั้งเครื่อง พิมพ์ งานหลังพิมพ์ แม่พิมพ์ และกำไรเป้าหมาย
- ใบเสนอราคาและใบงานผลิต พร้อมข้อมูลขนาดกล่องและรุ่น Artwork/Dieline
- ยืนยันความพร้อมก่อนเริ่มพิมพ์ และติดตามขั้นตอนผลิต
- จองกระดาษ เบิกผลิต สร้างคำสั่งซื้อ และรับวัสดุเข้าคลัง
- เปรียบเทียบต้นทุนประมาณกับต้นทุนจริงที่บันทึก
- สำรอง JSON และส่งออก CSV

- เลือกงานสติ๊กเกอร์แบบแผ่น วัสดุสติ๊กเกอร์กระดาษ/PP ขนาดดวง Ups เคลือบและ Kiss-cut

## ขอบเขตต้นแบบ

งานสติ๊กเกอร์ม้วนยังต้องพัฒนาเพิ่ม: หน้ากว้าง ความยาว ระยะซ้ำ จำนวนดวงต่อม้วน แกนและทิศคลายม้วน ไม่ควรใช้สูตรแผ่นแทนงานม้วน

ข้อมูลเริ่มต้นเป็นตัวอย่าง บันทึกผ่าน localStorage ในเบราว์เซอร์ของแต่ละคน ไม่ซิงก์ข้ามเครื่อง ไม่มีฐานข้อมูลกลางหรือสิทธิ์พนักงาน ยังไม่ได้เชื่อม PK WMS หรือ Odoo การอนุมัติแบบและ QC เป็นการยืนยันด้วยคน ไม่ใช่การตรวจไฟล์อัตโนมัติ กรุณาสำรองข้อมูลก่อนล้างข้อมูลเบราว์เซอร์

GitHub Pages เผยแพร่เว็บสาธารณะ การลงชื่อเข้าใช้ด้วย ChatGPT ของเว็บไซต์ Sites เดิมไม่ได้ใช้กับ URL นี้ เว็บไซต์นี้ไม่มีระบบเข้าสู่ระบบสำหรับพนักงาน

## โครงสร้างและการตรวจสอบ

`docs/` เป็นเว็บ HTML/CSS/JavaScript ที่ GitHub Pages เผยแพร่จาก branch `main` และ folder `/docs` ไม่ต้องติดตั้งแพ็กเกจหรือ build

ใช้ Node.js 18+ ตรวจสอบกติกาธุรกิจ:

```sh
node --test tests/core.test.cjs
node --check docs/app.js
```

แหล่งอ้างอิงอุตสาหกรรมอยู่ในเมนู “แนวทางและแหล่งอ้างอิง” ของเว็บไซต์
