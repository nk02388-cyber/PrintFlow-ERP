# PrintFlow ERP — กล่อง บรรจุภัณฑ์ และสติ๊กเกอร์

ระบบหลักคือ PrintFlow พร้อม backend ของตัวเอง ไม่มี Odoo หรือระบบธุรกิจอื่นเป็นฐาน

## เปิดเว็บ
- [เว็บต้นแบบบน GitHub Pages](https://nk02388-cyber.github.io/PrintFlow-ERP/) ใช้ข้อมูลในเบราว์เซอร์
- ระบบกลางสำหรับทดลองเครื่องนี้: http://127.0.0.1:8787/ หลังเริ่มเซิร์ฟเวอร์

## เริ่มระบบกลาง
ต้องมี Node.js 24.14+; ทดสอบด้วย 24.19.0 ไม่ต้องติดตั้งแพ็กเกจ

```sh
node server/server.cjs
```

เปิด http://127.0.0.1:8787/ แล้วตั้งชื่อและรหัสผ่านผู้ดูแลด้วยตัวเอง (อย่างน้อย 12 ตัวอักษร) ไม่มีรหัสผ่านเริ่มต้น ไม่มี fixture account ในฐานข้อมูลจริง ข้อมูลเริ่มต้นเป็นตัวอย่างสำหรับทดลอง

## ความสามารถ
- ประเมินราคาตามสเปกกล่อง/สติ๊กเกอร์ Ups วัสดุ เผื่อเสีย ตั้งเครื่อง เพลท สีพิเศษ แม่พิมพ์ บล็อกฟอยล์ และงานหลังพิมพ์
- ใบเสนอราคา → ใบสั่งขาย → ใบงาน พร้อมแผนเครื่อง/ขั้นตอนและดาวน์โหลดใบงานสำหรับพิมพ์
- ทะเบียนเครื่องมือ เจ้าของ สถานะ และต้นทุนอ้างอิง
- ไฟล์ Artwork/Dieline/Cutline และหลักฐานอนุมัติแต่ละรุ่น; เปลี่ยนรุ่นก่อนเริ่มผลิตต้องอนุมัติใหม่
- จองวัสดุแผ่น เบิกเมื่อเริ่มพิมพ์ รับ PO ครั้งเดียว และปรับใช้จริงด้วยเบิกเพิ่ม/คืนคลัง
- QC สี ขนาด รอยพับ/กาว หรือไดคัท/กาวสติ๊กเกอร์ พร้อมจำนวนผ่าน/เสียและประวัติ; QC ไม่ผ่านส่งมอบไม่ได้
- ต้นทุนจริง 7 หมวด เทียบประมาณและราคาขาย
- ลูกค้า/CRM ผู้ขาย เครื่องจักร BOM วางแผน งานจ้าง และซ่อมบำรุง
- ระบบกลางมีบัญชีพนักงาน บทบาทเขียน CSRF session version conflict transaction audit และฐานข้อมูลสำรอง

## ขอบเขตปัจจุบัน
ระบบกลาง binds 127.0.0.1 สำหรับทดลองบนเครื่องนี้ ยังไม่เปิดให้เครื่องอื่นหรืออินเทอร์เน็ต หน่วย inventory เป็นแผ่น BOM ยังไม่เบิกอัตโนมัติ งานจ้างยังไม่ทำ stock transfer ยังไม่จัดคิวเครื่องอัตโนมัติหรือบัญชี/ภาษี สติ๊กเกอร์แบบม้วนต้องเพิ่มสูตรหน้ากว้าง ความยาว Repeat และทิศคลายม้วน

ผู้ใช้ที่ล็อกอินทุกบทบาทยังอ่านข้อมูลธุรกิจทั้งหมดได้ บทบาทจำกัดการเขียน จึงต้องตกลงสิทธิ์อ่านข้อมูลต้นทุนก่อนนำข้อมูลจริงมาใช้

## การเก็บและสำรอง
ระบบกลาง: data/printflow.sqlite พร้อม WAL ใช้ฐานข้อมูลบนเซิร์ฟเวอร์ ไฟล์แนบอยู่ใน BLOB ผู้ดูแลดาวน์โหลดฐานข้อมูลสำรองได้ที่ “ระบบกลางและผู้ใช้” เก็บสำรองเป็นข้อมูลส่วนตัว ห้าม commit ฐานข้อมูลหรือ secrets

โหมด GitHub Pages: localStorage + IndexedDB ไม่มีระบบพนักงานหรือฐานข้อมูลกลาง JSON ไม่รวมเนื้อไฟล์แนบ ข้อมูลจากเว็บต้นแบบไม่ย้ายเข้าระบบกลางอัตโนมัติ
